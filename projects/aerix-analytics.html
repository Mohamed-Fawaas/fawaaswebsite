Project Overview

A frontend-only demo built with React, Vite, Recharts and Lucide icons. Data is persisted in localStorage.

Technologies & Languages Used

React
Vite
Recharts
JavaScript
CSS3
localStorage

Key Features

  • Sidebar with overview, analytics, projects, customers, settings
  • Area/bar charts with period selector
  • Add, delete, update status and search projects
  • Export filtered projects to CSV
  • Light/dark mode, notification panel, mobile nav
  • Reset demo data
