Project Overview

Pure HTML/CSS/JS app. Menu, prices, promo codes and hours live in js/data.js and everything saves in localStorage.

Technologies & Languages Used

HTML5
CSS3
JavaScript
localStorage

Key Features

  • Search, sort, categories, favourites, mood finder
  • Customise size, milk, sweetness, extras
  • Promo codes (BREW10, WELCOME20, FREESHIP)
  • Dine-in / takeaway / delivery with tip & service charge
  • Live order tracking
  • Table reservation with .ics calendar download
  • Loyalty stamp card, dark/light theme

How It Works – Main Functions
