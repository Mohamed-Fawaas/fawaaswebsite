Project Overview

A clean MVC-style CMS: PDO singleton database, Post/User/Category models, CSRF helpers, Apache security rules and an admin dashboard for posts, categories and users.

Technologies & Languages Used

PHP
MySQL
Bootstrap
JavaScript
TinyMCE

Key Features

  • Public home, post, category and search pages
  • Register/login/logout with roles
  • Admin dashboard stats
  • Post create/edit/delete with images (TinyMCE)
  • Category and user management
  • CSRF protection, .htaccess hardening
