Project Overview

CityCycle Rentals is a compact native Android (Java) app. Riders create an account stored in SQLite, log in, choose one of the available bikes and manage the active rental from a dedicated screen with a running HH:MM:SS timer, a +30 minute extension and an end-rental action that returns to the profile.

Technologies & Languages Used

Java
Android
SQLite
Gradle

Key Features

  • Sign-up and login using SQLite
  • Rent screen with three bikes
  • Live rental timer updated every second (Handler)
  • Extend rental by 30 minutes
  • End rental and return to the rider profile
  • Profile screen for the signed-in user

How It Works – Main Functions

1
RentalActivity.startRental

Passes the chosen bike ID to the rental management screen.

2
RentalManagementActivity.startRentalTimer

Handler loop that updates the HH:MM:SS timer every second.

3
Extend / End buttons

Adds 1800 seconds to the timer or stops the rental and opens the profile.

4
SignUpActivity / LoginActivity

Create and verify accounts in the local SQLite database.
