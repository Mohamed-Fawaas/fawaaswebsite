Project Overview

GestureControl AI is a Java Swing prototype. It tracks a green and a red marker through the webcam, converts their position to screen coordinates and uses Java Robot to drive the OS. A pinch (two markers close) triggers an action.

Technologies & Languages Used

Java
Java Swing
FlatLaf
Maven

Key Features

  • Live webcam preview with marker indicators
  • Cursor, scroll, presentation, media and screenshot modes
  • Pinch detection with 900 ms cooldown
  • Coordinate smoothing and hue calibration sliders
  • Emergency STOP control and action history

How It Works – Main Functions

1
MarkerDetector.java

Finds each coloured marker's centre from the camera frame using hue thresholds.

2
ControlEngine.java

Maps gestures to mouse, key and screenshot actions through java.awt.Robot.

3
App.java

Swing UI, camera thread, calibration and mode selection.

# Green sticker on index finger, red on thumb → Start Webcam → Enable OS Control
