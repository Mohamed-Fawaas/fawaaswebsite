Project Overview

GoRide LK V1 is a complete ride-hailing codebase: two Android apps (Kotlin, Jetpack Compose, Google Maps), a Node.js + Express + TypeScript backend with Socket.IO for live events, and a dark Next.js admin dashboard for operations.

Key Features

  • Phone + OTP login (dev OTP, SMS webhook adapter for production)
  • GPS pickup, map destination pin, Sri Lanka fallback places
  • Bike / Tuk / Mini / Car / Van with live fare, distance and ETA
  • Nearby driver markers and live driver tracking
  • Driver online/offline, accept, arrived, trip-OTP start, complete
  • Cash + mock card payment, ratings, SOS events
  • Admin dashboard: rides, drivers, revenue, SOS, editable pricing

How It Works – Main Functions

1
auth.ts

Issues JWT after OTP verification for passengers and drivers.

2
maps.ts

Google Routes / Geocoding adapter with offline Sri Lanka fallback.

3
utils.ts – fare engine

Calculates fare from distance, time and vehicle type.

4
server.ts + Socket.IO rooms

Ride state machine (requested → accepted → arrived → started → completed) broadcast live to passenger and driver.

5
store.ts

File-backed persistence for zero-setup development.

6
sms.ts

Pluggable SMS provider for real OTP delivery.
