Project Overview

HR System is a NetBeans Java Swing desktop application using MySQL. It separates access into admin, manager and assistant logins. Admins and managers create departments and designations and manage employee records (EPF number, email, department, designation), while assistants work with employee search and updates.

Technologies & Languages Used

Java
Java Swing
MySQL
JDBC
NetBeans IDE

Key Features

  • Separate admin, manager and assistant logins
  • Add, search, update and delete employees
  • Departments and designations management
  • Add managers and assistants
  • Role-specific menus
  • MySQL schema: admin, manager, asisstent, departments, employee

How It Works – Main Functions

1
DBConnection.connect

Opens the JDBC connection to the hrsystem database.

2
addemployeesnew / searchemployee

Insert, look up, update and delete employee rows.

3
adddepart / adddesignations

Maintain the departments and designations lists.

4
loginadmin / loginmanager / loginasisstent

Role-based authentication leading to each menu.

5
addmanager / addasisstent

Register new manager and assistant accounts.

How to Run

# Import hrsystem.sql into MySQL
# Update the connection URL and credentials in DBConnection.java
# Open in NetBeans and run, or: java -jar dist/HRSYSTEM.jar
