Project Overview

No framework or install: HTML, CSS and JavaScript with time-zone support.

Technologies & Languages Used

HTML5
CSS3
JavaScript
localStorage

Key Features

  • Animated analog and millisecond digital clock
  • 12H/24H and timezone selector
  • World clocks, ISO week, UTC offset
  • Stopwatch with laps, countdown timer
  • 4 themes, fullscreen, tick sound, saved preferences

How It Works – Main Functions

1
updateClock()

Runs each frame and updates hands and digits.

2
getISOWeek()

Computes the ISO week number.

3
timerTick() / swLoop()

Time-based loops for countdown and stopwatch.
