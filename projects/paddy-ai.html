Project Overview

Paddy AI is my final year project for my BSc. It joins three independent services – a React/Vite frontend, a Spring Boot REST backend with MySQL, and a Python FastAPI machine-learning service – so each part can be developed, tested and scaled on its own. A farmer registers, adds farms, runs AI predictions, keeps a history (with PDF export), gives feedback on predictions and gets live notifications. The whole UI is available in English, Sinhala and Tamil, and an admin panel manages the system.

Key Features

  • JWT login/registration + forgot/reset password by email
  • Land suitability prediction from soil & climate inputs
  • Paddy leaf-disease detection from a photo (Bacterial leaf blight, Brown spot, Leaf smut)
  • Irrigation, fertilizer, yield and pest-risk recommendations
  • Weather advisory page
  • Farm & farm-activity management
  • Prediction history with PDF export + farmer feedback on AI results
  • Live in-app notification bell
  • Role-protected Admin Panel
  • English, Sinhala and Tamil interface; responsive on mobile/tablet/desktop
  • ML-server-down banner instead of silent failures

How It Works – Main Functions

1
AuthController + JwtUtil + SecurityConfig

Register/login issues a signed JWT; Spring Security filters every request and protects Admin routes by role.

2
MLClientService

The backend forwards prediction requests to the FastAPI ML service (port 8000) and returns the JSON result to React.

3
ml-module/api/predict_*.py

Seven endpoints (disease, suitability, irrigation, fertilizer, yield, pest, weather) each load their saved .pkl / .keras model and run inference.

4
train_disease_cnn.py

MobileNetV2 transfer learning (frozen ImageNet base) trained on a rice-leaf-disease image dataset, saved as disease_model.keras.

5
train_*.py (tabular models)

Random Forest / Gradient Boosting classifiers and a Random Forest regressor for yield, trained on the CSV data in ml-module/data, with LabelEncoders & scalers saved as .pkl.

6
PredictionController + FarmController

Every prediction is stored per user so the History page can list, filter and export it as PDF.

7
NotificationService + NotificationBell.jsx

Server creates notifications; the React bell shows unread counts.

8
LanguageContext + AuthContext

React context providers for language switching (EN/SI/TA) and the logged-in session; an expired token redirects to Login.

How to Run

# 1) MySQL: create DB paddy_ai_db and import paddy_ai_db.sql
cd ml-module && python -m venv .venv && pip install -r requirements.txt
uvicorn api.main:app --host 127.0.0.1 --port 8000 --reload
cd backend && mvn clean spring-boot:run      # http://localhost:8080
cd frontend && npm install && npm run dev    # http://localhost:5173
