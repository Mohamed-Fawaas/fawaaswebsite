Project Overview

The Paws Shop is a NetBeans Java Swing desktop application backed by MySQL over JDBC. A manager dashboard handles cashiers, pet suppliers and categories, while cashiers log in to their own dashboard. Suppliers can be added, viewed, searched and updated, and cashier accounts are stored in the users table.

Technologies & Languages Used

Java
Java Swing
MySQL
JDBC
NetBeans IDE

Key Features

  • Login form with manager and cashier roles
  • Manager dashboard and cashier dashboard
  • Add and view cashiers (users table with salary)
  • Add, view, search and update pet suppliers
  • Add product categories
  • MySQL schema included (pawshop_users, pawshop_categories)

How It Works – Main Functions

1
LoginForm

Authenticates the manager or a cashier and opens the matching dashboard.

2
DBConnection.getConnection

Loads the MySQL driver and returns a JDBC connection.

3
Cashier/AddCashier, ViewCashier

Create and list cashier accounts.

4
PetSupplier/addPetSupplier, searchSupplier, ViewPetSupplier

CRUD and search for supplier records.

5
CategoryAdd/addCatgory

Stores product categories.

How to Run

# Import database/*.sql into MySQL (database: pawshop)
# Set URL, user and password in DBConnection.java
# Open in NetBeans and run, or: java -jar dist/The_Paws_Shop.jar
