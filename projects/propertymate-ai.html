Project Overview

PropertyMate AI connects tenants, landlords and admins. A Next.js client talks to an ASP.NET Core Web API (EF Core + SignalR) with SQL Server, and a separate FastAPI service provides the explainable AI features. Docker Compose starts everything together, and the repository includes SRS, architecture and test-strategy documents.

Key Features

  • Natural-language property search and ranked recommendations
  • Price estimate, affordability analysis, market prediction
  • Listing-quality scoring, description and image analysis
  • Risk flags for admin review (not proof of fraud)
  • Applications, appointments, agreements, reviews, saved listings
  • Real-time messaging and notifications (SignalR)
  • Tenant / Landlord / Admin roles with JWT
  • Swagger API docs, unit & integration tests, Docker Compose

How It Works – Main Functions

1
engine.parse_search()

Turns a sentence into structured filters (budget, rooms, place).

2
engine.rank_properties()

Scores each property by text match and criteria and returns the best matches with an explanation.

3
estimate_price / analyze_affordability

Estimators that return a value together with the factors behind it.

4
detect_risk / listing_quality

Flags suspicious listings and scores listing completeness for admins.

5
Controllers (Properties, Applications, Agreements …)

ASP.NET Core controllers expose REST endpoints; AIController proxies to the FastAPI service.

6
SignalR

Pushes chat messages and notifications instantly to connected users.

How to Run

cp .env.example .env     # set SQLSERVER_SA_PASSWORD and JWT_KEY
docker compose up --build
# Web http://localhost:3000 · API http://localhost:8080/swagger · AI http://localhost:8000/docs
