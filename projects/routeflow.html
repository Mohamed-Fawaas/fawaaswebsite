Project Overview

Customers track a shipment by reference and get an illustrative rate quote. Operators sign in to create consignments, record scan events and view performance reports; every event is stored transactionally.

Key Features

  • Public tracking timeline (no personal data shown)
  • Illustrative LKR shipping-rate estimator
  • Animated SVG/CSS cargo hero
  • Admin: new consignment, scan updates, ledger search/filter/edit
  • Performance reports and CSV export
  • Health check and admin reset script
