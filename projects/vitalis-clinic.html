Project Overview

The public site uses floating CSS 3D spheres, glass cards and scroll reveals. Requests are saved to MySQL; staff manage patients, doctors and appointments with row-locking to prevent double booking. Portfolio demo only – not for real patient data.

Key Features

  • Specialist cards and consultation request form
  • Requests inbox (new / contacted / closed)
  • Patient and doctor CRUD
  • Appointments with double-booking prevention
  • CSV export, reduced-motion support
